# SEPevo
This repository accompanies the manuscript "SEPevo: From Academic Pipeline to Enterprise Deployment— A tech transfer story with ROI ambitions", which was accepted for the 13th International Conference of Control Systems, and Robotics (CDSR 2026), June 07 - 09, 2026, Barcelona, Spain. Publisher is detailed at www.international-aset.com. 

# Abstract
In this paper, we describe a modular framework for explainable stock prediction using Large Language Models, Reinforcement Learning, and Parameter-Efficient Fine-Tuning. Using the Summarize–Explain–Predict (SEP) algorithm and Google Cloud Platform, which leverages Gemini-2.5-pro, our pipeline reworks noisy financial text to provide structured reasoning and predictions. Expensive expert annotations are saved thanks to agentic self-reflection — in which the model can generate "wrong/right" reasoning pairs to construct a reward model. Our framework enables expert-aligned forecasting and causal interpretations without creating a large overhead: full-parameter tuning for policy optimization is substituted by training LoRA adapters with a setup composed of SFT-RM-PPO. Validation performed on ten distinct test sets, shows a 10-fold increase in the Matthews Correlation Coefficient with respect to its predecessor [1], suggesting strongly improved ability of our algorithm’s implementation to provide transparent and reliable decision support. This upgrade of SEP pipeline (called SEPevo) started as a technology transfer purpose in firm Abaco SpA. to create a transparent and enterprise-level AI architecture, compliant with the EU AI act. Final target was the management of high-risk financial data of individuals for subsequent debt collection on behalf of public administration.

# Use
For further information, please contact [alberto_corradin@hotmail.com](mailto:alberto_corradin@hotmail.com). Additional details are available at [https://github.com/koa-fin/sep](https://github.com/koa-fin/sep).
SEPevo enhances the original algorithm published by Koa et al. (2004) and upgrades it; therefore, the commands to run it remain unchanged, as does the database used for training and testing this AI/ML pipeline ([https://github.com/koa-fin/sn2](https://github.com/koa-fin/sn2)).
The deployment of the algorithm was carried out on Google Cloud Platform (GCP). As a result, certain components of this repository require appropriate GCP API keys and authorization credentials to function correctly. In particular, scripts such as `requirements.lock.txt`, `mount_bucket.py`, and `build_project.py` are specific to the GCP-based deployment and may need adaptation for use in other environments.
